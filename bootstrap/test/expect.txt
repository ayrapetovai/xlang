# Expected behaviour for cases/*.x, checked by check.sh.
#
#   <file>  <rc>  <min-"stms">  <must-contain>
#
# rc 0 = parsed, 4 = rejected. "stms" appears once per statement in the AST
# dump, so its count is the statement count. The must-contain field is the rest
# of the line, so it may contain spaces; use "-" for none.
#
# A rejection case asserts the diagnostic text too, so that improving error
# reporting (TODO: "parser's error messages are bad") shows up here as a
# deliberate edit rather than a silent drift.
